# VISION — pocket-pet（会自己拿主意的桌面猫）

> 这一版从 pocket-tank 分叉出来：同一套本地小模型推理、同一套"反射层 + 顾问层"架构，
> 换掉的是**物种、状态、目标与世界**。本文件是 v1 的验收口径来源。

## 最终用户与核心价值

- **用户**：柠檬叔（以及任何想要一只"不需要联网、不需要云、会自己找事做"的桌面宠物的人）。
- **核心价值**：一块不到 ¥500 的板子上，**离线**跑着一只 14M 参数的"小脑"，
  它按自己的状态和性格挑事做；拔掉网线、断掉云，它照样是一只猫。
- **与前作的区别**：鱼缸的乐趣是"看鱼群 + 维持水质"；猫的乐趣是**陪伴与意外**
  （它会来蹭你、会半夜跑酷、会盯着窗外的鸟、会在猫砂盆前犹豫）。

## 成功长什么样（可验收）

1. **它像一只猫，而不是一台状态机**：无人干预连续运行 10 分钟，
   行为序列里**至少出现 5 种不同目标**，且**同一目标不连续出现超过 90 秒**
   （"无聊"字段的作用就是这个）。
2. **它对世界有反应**：给食物 → 30 秒内出现 `seek_food`；关灯 → 60 秒内出现 `sleep`；
   有人在旁边 → 出现 `follow_owner` 或 `hide`（取决于它的"粘人"值）。
3. **它有性格，而且性格是参数**：同一套权重，只改性格分布参数重新蒸馏，
   产出的行为差异**可量化**（例如"粘人 0.8 的猫"在留出集上 `follow_owner` 的比例
   比"粘人 0.2 的猫"高 ≥ 30%）。
4. **成本可复现**：从零到一只猫的全部标注花费 **≤ ¥40**（实测记账，见 ECN/计划证据）。
5. **零改动复用前作引擎**：`q4_model.c` 与 P4 PIE / S3 SIMD 内核**一行不改**。

## 非目标（v1 明确不做）

- 不做多物种（`species` 字段留钩子，v2 再说）。
- 不改推理引擎、不换网络架构（dim 384 / 8 层 / 8 头保持，否则要重写 SIMD 内核）。
- 不做语音、不做摄像头视觉、不做联网。
- 不做美术升级（沿用前作的像素精灵管线）。
