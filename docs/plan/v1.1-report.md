## 残余风险

1. **触摸未做**：现在只能从串口下命令，不符合"能玩"的完整预期。
2. **帧率 11**：可用但不够顺；脏矩形优化是明确的下一步。
3. **世界状态不持久**：断电重启后驱动力回到初始值（鱼缸有 nvs 存档，猫还没有）。
4. **`last`/`time` 在状态行里是近似的**：`time` 固定输出 `day`（还没接 RTC），
   `last` 跟的是最后一个完成的目标 —— 模型训练时见过的是采样分布，实机分布偏窄，
   这可能让实机决策比 77.4% 的一致率更保守。下一轮接 RTC 让 `time` 真实变化。
