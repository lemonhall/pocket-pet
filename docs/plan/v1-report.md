## 关键实测数字（可直接引用）

- **标注成本**：49,950 条 = **¥8.35**（空闲时段 + 前缀缓存命中 + 关闭思考模式 + 25 条/请求）
- **模型**：14.2M 参数（dim 384 / 8 层 / 8 头 / FFN 1024 / 词表 53 / seq 64）
- **一致率**：**77.3%**（563 条留出集，与训练集按状态行 hash 互斥）；多数类基线 12.8%
- **行为分布**（10 分钟模拟，6000 步）：sleep 1471 / play 1319 / follow_owner 1015 /
  explore 780 / scratch 544 / seek_food 493 / hide 236 / groom 142
- **训练时长**：7,227 条分层子采样 × 3 epochs ≈ 11 分钟（CPU；全量 4.5 万条 ≈ 80 分钟/epoch，故子采样）

## 残余风险

1. **M5 是真实断链**：现在只能说"架构对齐"，不能说"能在板上跑"。上板前不能宣称完整交付。
2. **一致率 77.3% 的构成**：混淆集中在 play↔explore/hide（语义相邻），
   但对"饿/困/猫砂"这三类硬需求几乎无错——行为上比数字看着更稳。
3. **时间尺度**：模拟里的 1 分钟 ≈ 真实猫的 1 小时（漂移速率是标定出来的），
   上板时要按真实帧率重标定。
4. **老师一致性**：rubric 是我的判断的显式化，学生学的是**我的口味**；
   若换一种口味（更粘人/更懒），需要改 rubric 走 ECN 并重训。
