# v1.1 计划：把猫做到 Tab5 上（能看、能玩）

> **把猫从"桌面上能跑"变成"板上能看能玩"**。设备当前跑鱼缸固件，猫固件做好直接覆盖。

## 里程碑

### M1.1-1 屏幕（把 BSP 接上）
- 拷 pocket-tank 的 `firmware/managed_components/` + `dependencies.lock`（**离线**，不重下组件）。
- 初始化照 `pocket-tank/firmware/main/display_port_tab5.c`：
  `bsp_feature_enable(BSP_FEATURE_LCD/TOUCH, true)` → 等 500 ms → `bsp_display_new_with_handles(&cfg, &h)` → `bsp_display_brightness_set(pct)`。
- 横屏：`esp_lcd_panel_swap_xy(panel, true)`，帧缓冲 **1280x720 RGB565**（1.84 MB PSRAM，双缓冲）。
- **验收**：日志出现 `Discovered board version 2 (LCD ST7123...)`；屏幕出画面（用户确认）。
- **反作弊**：不能只点亮背光就算过 —— 必须有像素内容（画一帧纯色 + 房间，用户确认看得见）。

### M1.1-2 房间与猫（渲染）
- `tools/export_cat_sprite.py`：`assets/siamese.png`（4x5 帧，32x32）→ RGB565 数组头文件（20 帧 ≈ 40 KB）。
- 画房间：地板/窗/猫爬架/食盆/**水碗**/猫砂盆/玩具/沙发，坐标取自 `pocket_pet/world.py` 的 ANCHORS（缩放到 1280x720）。
- 画猫：按状态选帧（走 3 帧 / 睡 / 正面 / 背面 / 低头），按朝向选行。
- **验收**：屏幕上能看见房间 + 暹罗猫（用户确认）；猫静止不动时也必须有正确的朝向帧。

### M1.1-3 世界循环 + 大脑
- 把 `pocket_pet/{world,sim,advisor}.py` 移植成 C：驱动力漂移、事件（人起身→躲）、目标到达即行动。
- 节流：每 **4 秒**问一次板上模型（`q4_model_decide` 限制在 8 个目标上），期间反射层按当前目标移动。
- 帧率目标：≥15 fps（房间+精灵是纯 blit，PPA 只做旋转/缩放）。
- **验收**：日志连续打印 `state -> goal`；10 分钟模拟里出现 ≥5 个不同目标。

### M1.1-4 交互（照鱼缸 director 的风格）
控制台命令（`esp_console`）+ 触摸点按：

| 命令 | 效果 | 画面反馈 |
|---|---|---|
| `food` | 食盆加满：`hunger` 的目标可达 | 猫走过来低头吃（低头帧），`hunger` 下降 |
| `water` | 水碗加水：新增 `thirst` 驱动 | 猫走过去喝水 |
| `play` | 逗猫棒：`bored` 拉高、玩具变近 | 猫扑玩具（走动帧加速） |
| `pet` | 撸猫：`scruff` 下降、`clingy` 上升 | 猫靠近人（沙发） |
| `clean` | 清猫砂盆：`litter` 归零 | 猫不再走向猫砂盆 |
| `status` | 打印全部驱动力 + 当前目标 + 上一目标 | 同时把该行打在屏幕上（小字） |
| `brain` | 重新读一次 Q4（热更新模型用） | — |
| `info` | 模型/内存/帧率 | — |

- **反作弊**：每个交互都必须给出**可判的驱动值变化**（`status` 前后对比，日志留证），不能只是打印一句话。

## 风险与已知坑

1. **BSP 的 `bsp_display_cfg_t` / `bsp_display_handles_t` 字段**没读过，先照 `display_port_tab5.c` 抄（那是能点屏的现存代码）。
2. **PPA 阻塞模式吃半帧**（19.9 ms）→ 用非阻塞 + 双缓冲（鱼缸的写法），否则帧率掉到个位数。
3. **背光与 LCD_EN 在 IO 扩展器上**，只用 BSP 的影子寄存器写法，**不要读-改-写**（会把 LCD_EN 弄掉变黑屏）。
4. **COM9 一打开就复位**：发控制台命令前要等一条启动日志（`tools/tab5_console.py --wait-for`）。
5. **触摸驱动的 100 kHz 默认速率**会让轮询 ~10 ms → 自己建 400 kHz 的 panel_io 再传给驱动（鱼缸实测 0.30 ms）。
6. 覆盖鱼缸固件前，鱼缸模型已有字节级备份：`pocket-pet/backup/fish_model_0x290000.bin`。
