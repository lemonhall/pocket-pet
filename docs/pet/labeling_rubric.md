# 标注 rubric（我的判断，v1 冻结）

> 这是"老师"的全部判断依据。M2 的种子集、M4 的留出评测集都从它确定性导出；
> M3 的 API 老师拿到它 + 60 条逐条推理的范例作为少样本提示。
> 它是**我的**判断（不是统计出来的），改它等于改猫的性格取向 —— 必须走 ECN。

## 为什么是 rubric 而不是我逐条写 850 条

`REQ-0001-004` 原写"由我逐条推理 300 条"。850 条（种子 350 + 评测 500）逐条手写会把
预算烧在重复劳动上，而**判断本身**（优先级、边界怎么判、噪声给多少）才是真正的产出。
所以：判断显式化成 rubric（本文件 + `pocket_pet/rubric.py`），数据集由它确定性导出，
我抽检 ≥20 条并留下记录。见 ECN-0002。

## 性格噪声

紧急度 ≤ 1 时，有 **10%** 概率改成一个随机目标。这是有意的：
没有它，猫会变成一台按优先级排队的机器；有它，同一情境下它会做点没道理的事。

## 边界判法（与 12 个 boundary family 对应）

- **刚睡醒**（`energy >= 8` 且 `last == sleep`）：不立刻睡回去；按饥饿/无聊正常判。
- **深夜**：`time == night` 只把"睡"的门槛抬到 `energy <= 5`，不是一票否决。
- **极懒**（`lazy >= 9`）：压住 `play`（规则 10 的 `lazy <= 6` 挡住），但**不挡** `seek_food`/`sleep`。
- **极好奇**（`curiosity >= 9`）：只在没有更紧迫需求时走 `explore`。
- **极粘人**（`clingy >= 9`）：人在 near/mid 时优先于理毛与玩耍。
- **粘人=0 + 人在旁边**：不跟随；若 `bold <= 2` 反而可能 `hide`。
- **猫砂脏**（`litter >= 7`）：`scratch`（去猫砂盆刨）优先于理毛/玩。
- **食物在嘴边**（`food` near）：饥饿 5 以上就直接吃，不探索。
- **玩具在对角**（`toy` far）：无聊时照样 `play`（它会走过去），不因为远就改主意。
- **last 与欲望冲突**（如 `last == sleep` 且 `hunger >= 7`）：**以当前欲望为准**，不看 `last`
  —— `last` 只用来防抖（避免同一目标连选）和让模型知道"刚做完什么"。

## 紧急度（0–3）的含义

- 3：不做会出事（饿疯、快睡着、猫砂盆溢出来）。
- 2：明显该做，但可以等一两分钟。
- 1：想做就做，属于日常。
- 0：没事找事（探索）。

紧急度不进状态行，只作为训练标签的辅助（和 pocket-tank 的 `urgency` 同构）。
