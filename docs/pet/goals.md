# 猫的八个目标（v1，冻结）

> 目标名唯一权威：`include/pet_state.h` 的 `PET_GOAL_LIST`。
> 顺序就是模型学到的 token id 顺序。
> REQ-0001-002 要求每个目标有 ≤2 行定义 + ≥3 条正例；正例来自种子标注（M2），
> 本节先给定义，M2 完成后回填正例。

| 目标 | 定义（≤2 行） |
|---|---|
| seek_food | 去食盆吃东西。饿值高或食盆就在附近时优先。 |
| sleep | 睡觉。精力低、或夜里无聊值也低时选它。 |
| play | 玩玩具/扑空气。无聊值高且精力尚可时出现。 |
| groom | 舔毛/理毛。毛乱值高时出现。 |
| follow_owner | 去人身边蹭。粘人值高、且人在近处或中距离时出现。 |
| scratch | 抓挠（猫爬架/沙发角）。无聊 + 好奇的组合，带一点破坏性。 |
| explore | 四处巡视。好奇值高、没有更紧迫需求时的默认行为。 |
| hide | 躲起来。胆大值低、或刚被吓到（人突然出现）时出现。 |

## 优先级（写给标注者与老师看）

饿 > 困 > 猫砂 > 粘人 > 玩 > 理毛 > 探索 > 躲。

允许约 10% 的"没道理"（随机偏好）作为性格噪声——这一点是有意的，
否则猫会变成一台按优先级排队的机器。
